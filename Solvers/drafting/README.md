# The drafting game: C++ solver and the formal proof of the draft

## Files

* `solver_drafting.cpp` — the C++ solver of the placement games (built by
  `make` in `Solvers/`; the values of all 924 placement games are in
  `results/placement_8x8.tsv`).

* `DraftWin.lean` — the draft as a game, independent of Pentominoes:
  - `canWin W pool h0 p0ToPick`: minimax for "can P0 force the draft to end in
    a winning split?" (`W` = set of winning splits for P0);
  - `play W s1 ...`: the draft in which P0 picks by minimax and P1 follows an
    arbitrary strategy `s1`;
  - `minimax_wins`: **if `canWin` says yes, then P0 following minimax ends in a
    split of `W`, against every strategy of P1.** Fully proved (only the
    standard axioms `propext`, `Classical.choice`, `Quot.sound`).
* `DraftTable.lean` — generated by `gen_table.py` from
  `results/placement_8x8.tsv`: the P0 hands with which P0 *wins* the
  placement game, for each variant (381 and 537 hands). Draws and P1 wins are
  not winning splits.
* `Pentomino8x8.lean` — the 8×8 statements:
  - `p0_wins_P0_places_first`, `p0_wins_P1_places_first`: P0 wins both
    variants (for every strategy of P1);
  - `winning_first_picks_P0_places_first`: the winning first picks are L, P, Y;
  - `winning_first_picks_P1_places_first`: every first pick except X wins;
  - `table_wellformed`: sanity checks of the data.
  The facts "`canWin` says yes" are established by `native_decide`, i.e. by
  running the compiled `canWin`; this adds one trusted step (Lean's compiler
  and runtime) on top of the proof.
* `DraftCheck.lean` — a separate executable (`draftcheck`) that reads the TSV,
  checks it, and solves the draft by complete minimax over all 12! pick
  sequences (no proof, about 12 minutes). Output of 2026-10-01 in
  `results/lean_checks/run_2026-10-01.out`.

## Build

In `Solvers/` (the Lean project covers both games):

    python3 drafting/gen_table.py   # regenerate DraftTable.lean from results/placement_8x8.tsv
    lake build                      # builds and checks all theorems (a few seconds)
    LEAN_PATH=.lake/build/lib/lean lean drafting/FinalCheck.lean   # prints the results and the axioms used
    ./.lake/build/bin/draftcheck ../results/placement_8x8.tsv     # optional, ~12 min

What is *not* covered: the correctness of the 924 placement outcomes in the
table itself; that rests on the C++ solver and its cross-checks.
